Google OAuth 권한과 전환 상태

기존 로컬 시험 연결에는 https://www.googleapis.com/auth/drive 권한이 부여되어 있습니다. 이는 Google 계정의 모든 Drive 파일을 조회·편집·생성·삭제할 수 있는 넓은 권한이며, 코드가 지정 파일만 처리한다는 사실과 OAuth 권한 자체의 범위는 다릅니다. 이 임시 시험 연결은 매일 자동백업에 활성화하지 않았습니다.

자동백업용 새 연결은 https://www.googleapis.com/auth/drive.file만 요청합니다. 이 권한은 사용자가 앱에 열어 주거나 선택한 파일과 앱이 생성한 파일을 조회·편집·생성·삭제할 수 있게 합니다. 폴더 선택만으로 모든 기존 하위 파일에 접근할 수 있다고 가정하지 않으며, 필요한 기존 복구키와 검증용 백업 파일도 개별 선택합니다. 백업 코드의 자동삭제는 비활성 상태입니다. 실제 동의·발급된 권한 및 저장·복원 검증이 끝나기 전에는 최소 권한 전환이나 자동백업 완료로 표시하지 않습니다.

접근하는 정보와 목적

사용자가 Google 동의 화면에서 선택한 파일·폴더의 식별자, 파일명, 크기, 소유·공유 권한 및 파일 내용에 접근하여 백업 저장, 비공개 여부 확인, 다운로드 무결성 확인과 복원을 수행합니다. 새 자동백업 인증 요청에는 전체 Drive 범위를 포함하지 않습니다. 기존 시험 승인의 철회 여부는 새 연결 검증 후 소유자가 결정합니다.

처리와 보관

업무 DB의 백업은 Google Drive로 업로드하기 전에 AES-256-GCM으로 암호화합니다. 복구키는 소유자의 결정에 따라 동일 Google 계정 내 별도 비공개 폴더에 보관합니다. 따라서 해당 계정에 접근하는 사람은 백업과 복구키 모두에 접근할 수 있습니다.

백업·복원 실행 중 필요한 평문은 임시 작업 공간에서 처리하고 실행 종료 시 정리하도록 구성합니다. OAuth 자격증명은 비공개 로컬 보호 저장소와 자동실행용 GitHub Secrets에 보관하도록 구성하며 코드 저장소·공개 로그·공개 다운로드에 포함하지 않습니다.

외부 처리 서비스

Google은 OAuth 인증과 Drive 보관을, GitHub Actions는 승인 후 예약 백업·복원 실행을 담당합니다. Healthchecks에는 실행 성공·실패 및 누락 감지를 위한 신호만 전달하도록 구성하며 고객 원문이나 백업 파일을 전송하지 않습니다.

이 앱은 Google 사용자 데이터를 광고·판매·신용평가·AI 모델 학습 목적으로 이용하지 않습니다. Google API를 통해 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 준수해야 합니다.

보관기간과 연결 해제

현재 백업 자동삭제는 비활성 상태입니다. 소유자가 보존 여부를 결정하며, 향후 보관정책을 활성화할 경우 별도 확인합니다. Google 계정에서 앱 접근 권한을 철회하면 이후 연결은 중단되지만 이미 만들어진 백업이 자동으로 삭제되지는 않습니다. 백업과 복구키 삭제는 소유자의 명시적 판단으로 별도 수행합니다.
